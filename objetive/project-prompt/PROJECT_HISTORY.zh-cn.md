# 项目历史

## 项目概述
- 目标：为"如何用 LLM/编码 Agent 写脚本或软件"这一需求，产出一套可复用的提示词模板。
- 项目类型：工具类（Prompt 模板 / AI 协作规范），非具体软件项目。

## 当前状态
- 已完成精简版 + 完整版提示词模板，各含中文/英文两份，共 4 个文件。

## 设计与关键决策
- 模板区分「精简版」（日常小任务）与「完整版」（复杂/大型项目）。
- 完整版额外包含「填写要点」和「能力边界」说明表格，供用户参考，不建议整段发给 Agent。
- 中英文件名约定：`<名称>.zh-cn.md` / `<名称>.en.md`，内容逐条对应。
- 强调三条核心原则：给真实输入/输出示例、验收标准要可验证、边界（范围/权限/停止条件/何时求助）必须写清楚。

## 关键参考
- 无外部数据表/参考设计；内容基于提示词工程通用实践总结。
