# 项目历史

## 项目概况

Chat Trace 是用于归档当前 session 历史问答的 OpenCode Skill。
用户选中的问题完整保留原文，对应 AI 回答简洁总结，
最终输出中英文两个 Markdown 文件。

## 当前状态

- 已保存功能规格：`docs/specs/chat-trace.md`。
- 已保存英文 Skill：`skills/chat-trace/SKILL.md`，并读取核对。
- 尚未安装到 `.opencode`，尚未进行实际问答归档验证。
- 功能规格尚未同步后续确认的规则调整。

## 设计与关键决策

- 固定四步流程：整理范围、展示问题选择表、
  生成已选问答预览、等待最终确认并保存。
- 两次确认必须分开：先确认问题选择，再确认最终内容和保存方案。
- 范围为当前 session，排除触发 Skill 的消息；不检索其他 session。
- 问题完整保留原文；不可读取时标记，不凭记忆重构。
  被选中的不可读取问题需补充原文后才能归档。
- 选择表仅包含编号和问题，编号使用数字并按对话顺序排列；
  最终预览保留所选问题的编号和顺序。
- Skill 本身使用英文，description 包含“记录提问”等中文触发词。
- 归档文件为 `PROJECT_TRACE.zh-cn.md` 和 `PROJECT_TRACE.en.md`，
  默认保存到当前工作目录。
- 两个归档版本均保留问题原文，AI 摘要分别使用中文和英文。
- 文件不存在时新建，存在时追加，不覆盖已有内容。
- 每批归档使用相同的二级时间标题分隔，时间取实际保存时间。
- 复杂问题可在表格下展示同编号完整原文，禁止用省略号替代内容。

## 注意事项与经验

- 长会话可能无法读取早期问题原文，摘要不能冒充原文。
- Markdown 表格中的换行、代码和竖线不能造成问题内容丢失。
- 规格保存、Skill 保存和问答归档是不同操作；
  保存 Skill 不等于批准归档当前对话。
